## Technical review resolutions
- Document fallback means exactly events that reach the document bubble listener; it must not circumvent a modal consumer's propagation boundary. Escape outside the Popover React subtree but inside an ancestor modal remains owned by that modal, as in the existing implementation. Accepted ancestor close removes the in-flow Popover with its React branch; no independent child portal is left. This unmodified outside-origin modal path is explicitly outside the child-event correction and must not be mistaken for the native outside-escape fixture, which contains a standalone Popover plus an outside button and no modal. Broader family-wide arbitration is not qualified here.
- Inside-event mechanism: an instance-local WeakSet<Event>, populated from onMouseDownCapture with event.nativeEvent. Check/delete membership at document bubble. Do not schedule a capture-time microtask to clear the identity: native three-engine proof shows that checkpoint runs BEFORE the document listener. If propagation stops, the weak key can be collected without a timer or strong retention; a different later event cannot match that identity. This supersedes the original mistaken end-of-dispatch cleanup requirement.
- Root merge: destructure the consumer onKeyDown out of rest, assign one composed JSX root handler, call the consumer first with the original event, then check defaultPrevented and run the Lyra Escape default in that same handler invocation. Never use stopImmediatePropagation or separate same-element native listeners. Root consumer stopPropagation cannot prevent the following statements in this one composed function. Compose the capture consumer similarly without a capture-time dismiss default.
- Existing modal-child Escape behavior refers to the current topmost modal authority gate. Lower modal ownership/inert/sibling decisions remain with the already-verified modal tranche; Popover does not override them.
