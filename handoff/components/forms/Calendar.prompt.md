# Calendar

Grid fixo de 42 células (6 semanas — o mês nunca muda de altura), semana começando no domingo, locale pt-BR. Hoje ganha anel, seleção ganha accent sólido, dias fora do mês ficam faint.

- **Range** (`range`): 1º clique define início, 2º define fim (inverte se anterior); extremos sólidos, miolo em accent-soft.
- **Mês/ano**: clicar no título sobe a granularidade (dias → meses → anos, blocos de 12); escolher desce de volta.
- Base de DatePicker e DateRangePicker.
