# TimePicker

Irmão do DatePicker: mesmo trigger `.lyra-input`, mesmo Popover; painel é uma lista rolável mono-espaçada de horários gerados por `step`/`min`/`max` que auto-rola até a seleção ao abrir. Valor é string "HH:mm" 24h (pt-BR) — sem Date para não carregar fuso. Lista em vez de colunas hora/minuto: um clique, um alvo, funciona no touch.
