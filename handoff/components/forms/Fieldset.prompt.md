# Fieldset / FormRow

Camada de composição de formulários: `Fieldset` agrupa campos com legenda + descrição (semântica nativa de `<fieldset>`), `FormRow` põe campos lado a lado em colunas iguais e colapsa para uma coluna abaixo de 560px. Elimina os grids manuais que cada tela escrevia para pares de Input.
