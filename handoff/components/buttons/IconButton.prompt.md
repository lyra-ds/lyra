Botão quadrado contendo apenas um ícone; use para ações compactas em toolbars, cards e linhas de tabela.

```jsx
<IconButton label="Configurações"><Icon name="settings" /></IconButton>
<IconButton label="Excluir" variant="ghost"><Icon name="trash-2" /></IconButton>
```

- `label` é obrigatório (acessibilidade).
- Mesmos variants/sizes do Button; default `secondary` + `md` (40×40).
