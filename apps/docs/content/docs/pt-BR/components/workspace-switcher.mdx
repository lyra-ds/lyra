# WorkspaceSwitcher

WorkspaceSwitcher muda o workspace atual e informa esse estado selecionado. Escolha-o em vez de Dropdown
quando a escolha for uma conta ou tenant, não uma ação executada no contexto atual.

## Exemplos

<Example id="selection" title="Workspace atual controlado">
  Passe `current` com `onChange` quando a aplicação for dona do workspace ativo. Sem `current`, o
  primeiro workspace aparece, o que serve apenas quando esse padrão corresponde ao estado ao redor.
</Example>

<Example id="create" title="Ação de criar">
  Providing `onCreate` renders a separate create action after the workspace list — a native button
  inside the popover but outside the listbox. Activating it calls `onCreate` and closes the popover,
  restoring trigger focus; it never fires `onChange`. `createLabel` should name the next workflow,
  not repeat the current workspace's name. `defaultOpen` exists for visual demos; keep it out of
  ordinary examples and application flows.
</Example>

## Quando usar

Use WorkspaceSwitcher quando uma pessoa selecionar o workspace, conta ou tenant que enquadra a página.

Prefira outro componente quando:

- **A lista contém comandos para o contexto atual** — use Dropdown, que é um menu.
- **A escolha é uma entre poucas visualizações pares** — use Tabs.
- **A pessoa precisa encontrar um destino ou comando no produto inteiro** — use CommandPalette.

## Acessibilidade

- In React, the trigger has `aria-haspopup="listbox"`, `aria-expanded` and `aria-controls`. Its
  popup holds a `role="listbox"` labelled by a visible "Workspaces" label, and each workspace is a
  `role="option"` with `aria-selected`; when present, the create action is a native button after the
  listbox, separated by an `<hr role="presentation">` — a command, not an option.
- In React, Enter, Space, ArrowDown and ArrowUp prefer the selected workspace when opening and
  fall back to the first option whenever workspaces exist. An empty list with `onCreate` focuses
  the create action; an entirely empty list retains trigger focus. In the list, ArrowDown and
  ArrowUp wrap among workspace options, Home and End jump to the ends, and Escape restores trigger
  focus. Arrows, Home and End skip the create action: native Tab moves from the roving option to
  it, Shift+Tab returns to the roving option, and Tab from the create action exits forward. Tab
  closes the popover when there is no create action, always without preventing native sequential
  focus.
- O componente move o foco DOM real entre opções, diferente do modelo de descendente ativo de
  CommandPalette. Ele também vira para cima quando não há espaço abaixo do gatilho.
- In React, `onChange` receives both the selected id and workspace record. Update the surrounding
  application state there; `current` is how a controlled switcher announces that state on the next
  render.

The Alpine integration supports selecting among consumer-served workspaces only: there is no create
binding or create event, and creation stays outside this component. Your markup serves the trigger
and listbox IDs, the visible label and each option's `aria-selected`; the binding never rewrites
that served `aria-selected` or the visible current-workspace content — your application code owns
those updates. Enter, Space, ArrowDown and ArrowUp all open onto the served selection when one is
available; when none is served, ArrowDown opens onto the first option and ArrowUp onto the last.
Selecting emits `lyra:change` with the activated workspace's `data-id`, closes the popover and
returns focus to the trigger; Tab closes without blocking native sequential focus.

```html
<div id="workspace-switcher" class="lyra-wssw" x-data="lyraWorkspaceSwitcher()">
  <button
    id="workspace-switcher-trigger"
    class="lyra-wssw__trigger"
    type="button"
    tabindex="0"
    aria-haspopup="listbox"
    aria-expanded="false"
    aria-controls="workspace-list"
    x-bind="trigger"
  >
    <span class="lyra-wssw__id">
      <span class="lyra-wssw__name">Atlas</span>
      <span class="lyra-wssw__plan">Pro</span>
    </span>
  </button>
  <div
    id="workspace-list"
    class="lyra-wssw__pop"
    role="listbox"
    aria-labelledby="workspace-label"
    style="display: none"
    x-bind="popover"
  >
    <span class="lyra-wssw__pop-label" id="workspace-label">Workspaces</span>
    <button
      class="lyra-wssw__item"
      type="button"
      role="option"
      aria-selected="true"
      data-id="atlas"
      x-bind="option"
    >
      <span class="lyra-wssw__id">
        <span class="lyra-wssw__name">Atlas</span>
        <span class="lyra-wssw__meta">Pro · 12 members</span>
      </span>
    </button>
    <button
      class="lyra-wssw__item"
      type="button"
      role="option"
      aria-selected="false"
      data-id="northstar"
      x-bind="option"
    >
      <span class="lyra-wssw__id"><span class="lyra-wssw__name">Northstar Studio</span></span>
    </button>
  </div>
</div>
```
