# Badge

Badge é um rótulo pequeno e presentacional para status, contagens e metadados. Escolha um `tone`
semântico para a cor carregar significado e use `dot` como indicador de status imediato.

## Uso

<CodeBlock>{`import { Badge } from '@lyra-ds/react';

export function Exemplo() {
  return (
    <>
      <Badge tone="success" dot>Ativo</Badge>
      <Badge tone="warning">Pendente</Badge>
      <Badge tone="danger">Falhou</Badge>
    </>
  );
}`}</CodeBlock>
