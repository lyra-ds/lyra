# Dialog

Dialog é um modal controlado com portal, retenção de foco, bloqueio de rolagem e caminhos de
fechamento acessíveis.

## Uso

<CodeBlock>{`'use client';

import { Button, Dialog } from '@lyra-ds/react';
import { useState } from 'react';

export function Exemplo() {
  const [open, setOpen] = useState(false);

return (

<>
<Button onClick={() => setOpen(true)}>Abrir diálogo</Button>
<Dialog open={open} onClose={() => setOpen(false)} title="Excluir projeto">
Esta ação não pode ser desfeita.
</Dialog>
</>
);
}`}</CodeBlock>
