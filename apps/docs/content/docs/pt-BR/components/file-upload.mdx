# FileUpload

FileUpload é uma área de upload não controlada para adicionar arquivos pelo seletor do navegador ou por
arrastar e soltar. Escolha `accept`, `multiple` e `maxSizeMB` conforme as regras reais do servidor; o
retorno de tamanho ajuda a recuperar, mas não substitui validação no servidor.

## Exemplos

<Example id="default-items" title="Tipos aceitos e arquivos existentes" layout="block">
  `accept` chega ao input de arquivo oculto e também compõe o texto auxiliar visível. `defaultItems`
  inicia uma lista não controlada existente, útil quando o formulário já tem assets enviados.
</Example>

<Example id="on-files" title="Entrega de arquivo único" layout="block">
  Defina `multiple={false}` quando a próxima etapa precisar de um arquivo. `onFiles` recebe objetos
  `File` do navegador, enquanto `onChange` informa os itens de exibição e o progresso simulado.
</Example>

## Quando usar

Use FileUpload quando pessoas precisam adicionar um ou mais arquivos e necessitam de drop, seletor, validação e progresso no mesmo lugar.

Prefira outro componente quando:

- **O formulário só precisa do campo de arquivo simples do navegador** — use Input com `type="file"` quando não for necessária área de drop nem lista de upload.
- **As pessoas editam metadados digitados, não adicionam um arquivo** — use Input ou Textarea para o valor.
- **Arquivos remotos existentes precisam ser navegados e gerenciados** — use uma visualização de gerenciador de arquivos, não uma área só de upload.

## Acessibilidade

- A área de drop é um `<button>` nativo, então recebe foco e abre o input de arquivo nativo oculto ao clicar.
- Arrastar altera o estado visual, enquanto pessoas no teclado mantêm o mesmo caminho do seletor pelo botão.
- Cada item concluído inclui `.lyra-upload__check` com `role="img"` e nome acessível “Upload complete” por padrão. Passe `doneLabel` para traduzi-lo; `removeLabel` recebe o nome de cada arquivo para que o rótulo de remoção siga a ordem natural do idioma.
- O `label` visível é texto do botão, não um `<label>` de formulário. Deixe ação e regras de arquivo claras com `label`, `hint`, `accept` e instruções próximas.
