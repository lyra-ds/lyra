# Compatibilidade

Styles, React e Alpine são publicados com SemVer independente. Cada pacote recebe apenas o bump que
sua própria superfície pública exige; um pacote sem mudanças mantém a versão. Quando um contrato
compartilhado de CSS, markup, estado ou comportamento muda, os pacotes afetados ainda são publicados
em uma mesma janela documentada, com um registro conjunto de compatibilidade e migração.

## Versões atuais

| Pacote            | Versão atual | Peers                                  |
| ----------------- | ------------ | -------------------------------------- |
| `@lyra-ds/styles` | 0.5.0        | nenhum                                 |
| `@lyra-ds/react`  | 0.5.0        | `react >=18 <20`, `react-dom >=18 <20` |
| `@lyra-ds/alpine` | 0.6.0        | `alpinejs >=3.13 <4`                   |

## Compatibilidade testada

| Faixa do Styles | Faixa do React | Faixa do Alpine | Status                                  |
| --------------- | -------------- | --------------- | --------------------------------------- |
| `=0.5.0`        | `=0.5.0`       | `=0.6.0`        | Testadas juntas na versão atual do Lyra |

Essas faixas exatas são intencionalmente estreitas: elas registram combinações testadas pelo
projeto, não toda combinação que um resolvedor npm consegue instalar. Uma versão posterior de um
pacote só amplia ou substitui a linha depois da verificação do contrato compartilhado.

## Como ler a matriz

- **Styles é o contrato visual compartilhado.** React e Alpine emitem suas classes `.lyra-*`; use
  uma linha testada em vez de presumir que números de versão iguais são compatíveis.
- **React e Alpine não dependem um do outro.** Instale apenas o adaptador usado pelo seu aplicativo,
  ou ambos quando superfícies diferentes precisarem deles.
- **Releases de contrato compartilhado são coordenados, não forçados.** Cada pacote afetado recebe
  seu próprio bump na mesma janela; pacotes não afetados mantêm suas versões.

## Suíte Lyra v1.0

A suíte Lyra v1.0 só é declarada depois que Styles, React e Alpine publicarem `1.0.0` de forma
independente e uma linha de compatibilidade testada registrar o contrato mútuo. Um pacote chegar a
`1.0.0` antes dos outros não conclui a suíte.

## Compatibilidade do Blade

A versão downstream atual é `lyra-ds/blade` v0.10.0, um pacote Composer publicado separadamente e
com SemVer independente. Ela não bloqueia a suíte Lyra v1.0, e a compatibilidade com Styles e Alpine
deve vir da
[matriz de compatibilidade do Blade](https://github.com/lyra-ds/blade#compatibility), não da tupla npm
acima.

## Fontes

Plus Jakarta Sans e JetBrains Mono são peers de todo o sistema, nunca embutidas:

```bash
npm i @fontsource/plus-jakarta-sans @fontsource/jetbrains-mono
```

Instalá-las você mesmo é o que permite controlar como elas carregam — auto-hospedadas, com subset,
com preload ou trocadas pela fonte da sua marca via `--brand-font`.
