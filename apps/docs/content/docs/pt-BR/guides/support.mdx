## Estabilidade dos componentes

A estabilidade do ciclo de vida é separada da disponibilidade do adaptador. FileUpload é Estável
sob o perfil Automated Core. Todas as outras entradas do catálogo permanecem Beta nesta versão;
Tabs, DataTable e a família de overlays formam o limite de migração P1 nomeado para a posterior
versão 1.0.0.

<h2 id="automated-browser-gate">Gate automatizado de navegadores</h2>

O Lyra v1.0 exige um gate automatizado com Playwright 1.62.1, Chromium revisão 1234
(`151.0.7922.34`), Firefox revisão 1538 (`153.0`) e WebKit revisão 2336 (`26.5`). O CI atual executa
essa matriz fixada de Chromium, Firefox e WebKit dentro do job `test` existente.

## Tecnologia assistiva manual

Sob o perfil beta Automated Core ativo, a evidência manual de Windows/NVDA e macOS/VoiceOver fica
`deferred-by-release-profile`: é uma evidência pós-lançamento não bloqueante, e não um resultado
aprovado. Nenhuma revisão de tecnologia assistiva é apresentada como concluída. O perfil Full
opcional preserva esses registros manuais e os procedimentos condicionais de mobile como requisitos
mais rigorosos.

<h2 id="what-support-means">O que suporte significa</h2>

A matriz usa apenas os níveis CSS, com aprimoramento Alpine, React e Não compatível. Um nível
descreve o contrato do adaptador documentado, não paridade entre adaptadores. Suporte significa que
o contrato aplicável cobre teclado, gerenciamento de foco e markup semântico; SSR e hidratação;
temas, cores forçadas, RTL, movimento reduzido, zoom e reflow. Toda entrada Não compatível expõe a
capacidade ausente, o motivo, o impacto para quem usa, a alternativa, o status da evidência e quem
reavaliará.

<h2 id="blade-timing">Momento do Blade</h2>

As células de Blade publicam o comportamento CSS ou com aprimoramento Alpine presente no artefato
lançado `lyra-ds/blade` v0.10.0 e no snapshot de API do repositório. Elas não afirmam paridade com
um contrato futuro do Lyra v1. Depois que um contrato React afetado se estabilizar, Blade exige uma
atualização de compatibilidade e um registro de evidência separados. Blade é um adaptador downstream
existente e não bloqueia o Lyra v1.0.
