## Instalação

Instale o pacote React e os estilos, e importe o CSS uma única vez na raiz do app.

```bash
npm i @lyra-ds/react @lyra-ds/styles
```

```tsx
// entrada do app (main.tsx / layout.tsx)
import '@lyra-ds/styles/styles.css';
```

## Seu primeiro componente

```tsx
import { Button } from '@lyra-ds/react';

export function App() {
  return <Button>Olá, Lyra</Button>;
}
```

## Tema escuro

Adicione <code>data-theme="dark"</code> ao elemento `<html>`. Todos os tokens semânticos respondem
automaticamente — sem trabalho por componente.

```html
<html data-theme="dark"></html>
```
