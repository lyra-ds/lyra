# Brand

Lyra is identified by a four-point Vega star and a concise, direct voice. Use these assets and
patterns consistently so the product remains recognisable across surfaces and contexts.

## Logo

The mark is the four-point Vega star. Pair it with the `Lyra` wordmark in Plus Jakarta Sans
extrabold with display tracking. Use the dark mark on light surfaces and the light mark on dark
surfaces; do not redraw, recolour or separate the mark from its proportions.

## Favicon

Use the indigo-square star for browser and device icons. Keep the supplied file for each target:
`/favicon.svg` for scalable contexts, `/favicon-32.png` for a standard browser icon,
`/favicon-180.png` for Apple touch icons, and `/favicon-512.png` for PWA metadata.

## Voice and tone

Write product copy as a clear conversation with the person using the product. Speak directly to
`you`, say what happened and what to do next, and keep the warmth practical rather than performative.

| Do                                                                             | Avoid                                                                       |
| ------------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| “Your workspace is ready. Invite a teammate when you’re ready to collaborate.” | “A workspace has been initialized for the user.” — impersonal construction. |
| “You’ve used 90% of this month’s calls.”                                       | “Yikes!! Something went wrong 😢” — emoji and exaggerated tone.             |
| “We couldn’t save your changes. Try again.”                                    | “OPERATION COMPLETE.” — robotic all-caps.                                   |

Do not use emoji in UI copy. Prefer a precise recovery message to a generic error, and write in the
same natural voice whether the message confirms success, explains a limit or asks for the next step.
