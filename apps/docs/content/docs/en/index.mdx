## Installation

Install the React package and the styles, then import the stylesheet once at your app root.

<CodeBlock>{`npm i @lyra-ds/react @lyra-ds/styles`}</CodeBlock>

<CodeBlock>{`// app entry (main.tsx / layout.tsx)
import '@lyra-ds/styles/styles.css';`}</CodeBlock>

## Your first component

<CodeBlock>{`import { Button } from '@lyra-ds/react';

export function App() {
  return <Button>Hello Lyra</Button>;
}`}</CodeBlock>

## Dark theme

Add <code>data-theme="dark"</code> to your `<html>` element. Every semantic token responds
automatically — no per-component work.

<CodeBlock>{`<html data-theme="dark">`}</CodeBlock>
