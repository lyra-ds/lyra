Lyra ships the whole look as `.lyra-*` classes, with light and dark themes and white-label
theming in four tokens. The React package is a thin wrapper over those classes, so the same
core works outside React too.

New here? [Getting started](/en/guides/getting-started) takes you from install to your first
component in a few minutes.
