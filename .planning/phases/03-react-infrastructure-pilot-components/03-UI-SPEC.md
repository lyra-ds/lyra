# Phase 3 — UI Design Contract

> Visual and interaction contract for the four pilot components (Button, Input, Dialog, Icon) of `@lyra-ds/react`. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Nature of this phase:** This is a component-library phase, not an app-screen phase. The design system already exists and is frozen — `@lyra-ds/styles` (Phase 2, shipped) carries the 209 handoff tokens and 248 `.lyra-*` classes. The React wrappers add ZERO visual decisions: every pixel comes from CSS the wrappers merely emit classes for. This contract therefore (a) records the frozen token values the pilots consume so the checker/auditor can verify against them, and (b) locks the interaction + state contracts (loading, error, focus, exit animation, unknown-icon) that Phase 4 will repeat 36 more times.

**Hard rule (from PROJECT.md + RCT-02/RCT-03):** wrappers must emit exactly the shipped `.lyra-*` classes — never restyle, never inline visual styles, never import CSS into the react package. Consumer `className` appends after `.lyra-*` classes (D-09).

| --space-4 | 16px | md control padding, dialog footer vertical padding |

## Typography

Frozen handoff tokens from `packages/styles/tokens/typography.css`. Roles below are the subset the four pilots actually render:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body / Dialog body (`.lyra-dialog__body`, `.lyra-input`, `.lyra-btn` md) | 14px (`--text-base`) | 400 body / 600 button | 1.5 (`--leading-normal`); buttons `line-height: 1` |
| Label (`.lyra-label`) / sm controls | 13px (`--text-sm`) | 600 (`--weight-semibold`) | 1.5 |
| Hint / error (`.lyra-hint`, `.lyra-hint--error`) | 12px (`--text-xs`) | 400 hint / 500 error | 1.5 |
| Heading (`.lyra-dialog__title`) | 18px (`--text-lg`) | 700 (`--weight-bold`), `--tracking-heading` −0.02em | inherits (tight block) |

lg controls step up to 16px (`--text-md`). The full 11-size/5-weight token ramp exists in the styles package and stays untouched; wrappers must never set `font-*` properties — typography arrives via `.lyra-*` classes only.

## Color

Frozen semantic aliases from `packages/styles/tokens/colors.css`; dark values switch via `[data-theme="dark"]`, brand override via `[data-brand]` + 4 tokens (STY-03/STY-04, already shipped and tested).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--surface-page` #F8FAFC light / #0E1023 dark | page background (fixtures/scratch apps) |
| Secondary (30%) | `--surface-card`/`--surface-raised` #FFFFFF light / night-900/800 dark | Dialog panel, Input field, secondary Button |
| Accent (10%) | `--accent` #5B5BD6 (indigo-600) light / #6E6ADE (indigo-500) dark | see reserved-for list |
| Destructive | `--danger` #DC2626 light / #EF4444 dark | `.lyra-btn--danger`, `.lyra-input--error` border + error focus ring, `.lyra-hint--error` text — nothing else |

Accent reserved for: `.lyra-btn--primary` background, `.lyra-btn--soft` background/text (via `--accent-soft`), `:focus` border (`--border-accent`) + focus ring (`--focus-ring`/`--shadow-focus`), text links. Ghost and secondary buttons are explicitly NOT accent-colored.

Overlay: `--surface-overlay` rgba(15,23,42,.48) light / rgba(8,9,24,.64) dark + 3px backdrop blur (`.lyra-dialog-overlay`, frozen).

Wrappers must never hardcode any color — all color flows through `.lyra-*` classes so light/dark/white-label keep working with zero JS.

## Motion (interaction contract — pilot-critical)

| Element | Behavior | Tokens |
|---------|----------|--------|
| Dialog overlay enter | `lyra-fade-in` (0.6→1 opacity — never from 0, per constraint) | `--duration-base` 180ms, `--ease-out` |
| Dialog panel enter | `lyra-pop-in` — transform only: scale(.97) translateY(4px) → identity | `--duration-base` 180ms, `--ease-out` |
| Dialog exit (NEW, D-17/D-18) | `.lyra-dialog--closing` (+ overlay counterpart) — reverse of the entry transform, transform/opacity-to-visible only; component stays mounted via `usePresence` until transitionend/animationend, then unmounts | mirror entry: 180ms `--ease-out`; class names go on the additive-extensions allowlist |
| Button/Input state transitions | background/border/color/box-shadow at `--duration-fast` 120ms (frozen) | — |
| Spinner | `lyra-spin` 0.7s linear infinite (frozen) | — |

Entry-animation constraint holds for the new exit CSS too: no `opacity: 0` at any ENTRY frame start; exit may fade out.

## Copywriting Contract

The pilots are white-label primitives — all user-facing copy is consumer-provided via props. The library-owned strings are:

| Element | Copy |
|---------|------|
| Primary CTA | not applicable at library level — consumer-provided `children`; fixture/scratch apps use realistic verb+noun labels (e.g. "Save changes", "Create project"), never "Submit"/"Click here" |
| Dialog close button `aria-label` | `Close` (EN canonical, per D-23/JSDoc-EN policy; localizable later via prop per deferred PV-04) |
| Icon unknown-name dev warning | `[lyra-ds] Icon: unknown name "{name}". It is not in the curated registry — pass a lucide-react component via the \`icon\` prop instead.` — `console.warn` gated by `process.env.NODE_ENV !== "production"`, renders `null` (D-05) |
| Empty state heading / body | not applicable — no data-driven views in this phase |
| Error state | Input: `error` prop string replaces `hint` and switches to `.lyra-hint--error` + `.lyra-input--error`; message content is consumer-owned; wrapper wires `aria-invalid="true"` + `aria-describedby` to the error node |
| Loading state | Button `loading`: spinner shown, label REMAINS visible (no layout shift), `aria-busy="true"`, interaction blocked via `.lyra-btn--loading` + `disabled` semantics |
| Destructive confirmation | none in this phase — `variant="danger"` is a style only; confirmation flows are consumer app logic |

All JSDoc on the pilot components: canonical English (translated from pt-BR handoff `.d.ts` during conversion — locked convention feeding Phase 5 docgen).

## Component Interaction Contracts (pilot-specific)

### Button (simple pilot)
- States styled by CSS (must all be emitted correctly): default, `:hover`, `:active` (0.5px translateY), `:focus-visible` (`--shadow-focus` ring), `:disabled` (opacity .5), `--loading`
- Variant map: `variant` → `.lyra-btn--{primary|secondary|soft|ghost|danger}` (default primary); `size` → `--{sm|md|lg}` (default md); `full` → `--full`; icon-only → `--icon`
- Accessible name: icon-only Buttons (`--icon`) REQUIRE `aria-label` — fixtures must demonstrate it, and `packages/react/CONVENTIONS.md` must state it as a conversion-checklist rule (axe suite enforces at runtime)
- `iconLeft`/`iconRight` render at 16px inside the 8px-gap flex row

### Input (form/controlled pilot)
- DOM: `.lyra-field > .lyra-label? + (.lyra-input-wrap? > .lyra-input-wrap__icon? + .lyra-input) + .lyra-hint?`
- Controlled/uncontrolled via `useControllableState` (D-14): controlled when `value !== undefined`
- A11y wiring: `label` ↔ input via `htmlFor`/`useId`; `hint`/`error` via `aria-describedby`; `error` sets `aria-invalid`
- Size modifiers `.lyra-input--{sm|lg}`, error modifier `.lyra-input--error`

### Dialog (overlay pilot)
- DOM preserved: `.lyra-dialog-overlay > .lyra-dialog > (__header > __title + __close) + __body + __footer?`; `div` + `role="dialog"` + `aria-modal="true"` (D-15), `aria-labelledby` → title via `useId` (D-20)
- Portal: `container` prop, default `document.body`, SSR-guarded (D-21); scroll lock with scrollbar-width compensation (D-22)
- Focus: trap while open; initial focus = first focusable, fallback panel `tabIndex={-1}`; restore to origin on EVERY close path (Esc, overlay click, ×) — close paths individually flaggable `closeOnEsc`/`closeOnOverlayClick` default true (D-16)
- Exit: keep-mounted-while-closing via `usePresence` + `.lyra-dialog--closing` (D-17/D-18)

### Icon (registry pilot)
- Inline `<svg>` via lucide-react with class `.lyra-icon`, `currentColor` default, `size` default 20 (D-06 — the prototype's `<span>`+mask is dropped, visual output identical)
- `name` typed as the 54-name literal union `IconName` (D-04); unknown at runtime → dev warn + `null` (D-05)
- `title` prop → accessible label; absent → `aria-hidden="true"` (handoff contract)
