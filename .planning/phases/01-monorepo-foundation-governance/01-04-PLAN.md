## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PR authors (anyone) -> CI runner | Untrusted forks trigger workflow runs; event payload is attacker-controlled data |
| Action marketplace -> workflow | Third-party action code executes with repo checkout access |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1-01 | Tampering | mutable third-party action tags (pnpm/action-setup) | high | mitigate | Pin pnpm/action-setup to full commit SHA; first-party actions/* at major tag (SHA preferred later); actionlint pinned to 1.7.12 |
| T-1-02 | Elevation | over-privileged GITHUB_TOKEN | medium | mitigate | Top-level `permissions: contents: read`; widen per-job only when Phase 7 release automation needs it |
| T-1-05 | Tampering/Elevation | script injection via event data in run: steps | high | mitigate | No event-string interpolation in any run: step; no privileged PR-trigger variant; actionlint flags violations in CI |
| T-1-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new installs in this plan (CI uses --frozen-lockfile only); legitimacy checkpoint enforced in plan 01-02 |
</threat_model>
