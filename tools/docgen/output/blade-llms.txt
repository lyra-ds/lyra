## Blade components (lyra-ds/blade v0.10.0)

One `<lyra:*>` tag per component, rendered server-side by Laravel. Every tag emits the
same `.lyra-*` classes as the other stacks; interactive ones serve the HTML that an
Alpine binding animates. Never invent a tag or a prop — this list is the whole surface.

### <lyra:accordion>

Behavior comes from the `lyraAccordion()` Alpine binding (`@lyra-ds/alpine`); the tag serves the HTML it animates.

- `items` — required
- `defaultOpen` — default `null`
- `multiple` — default `false`

```blade
<lyra:accordion :items="[
    ['id' => 'billing', 'title' => 'Billing', 'content' => 'Invoices are issued on the first business day of each month.'],
    ['id' => 'security', 'title' => 'Security', 'content' => 'Two-factor authentication is required for every workspace owner.'],
]" default-open="billing" />
```
